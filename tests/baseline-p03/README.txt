P03 基线夹具（前后性能比较用，请勿删除或修改）
=============================================

这些文件是 P03 开工前工作树版本（P02 接受后）的字节快照，配合同目录 MANIFEST.txt 的
SHA-256 使用。tests/p03-bounded-performance.cjs 会断言哈希匹配，并把这些文件里的
真实 app.js / db.js / sync.js / api-shim.js 代码装进隔离环境，与当前实现做同一样本的
前后比较（1 次预热 + 5 次中位数）。

用途仅限于只读比较：不参与打包、不被 App 加载。
如需重新生成基线，请等战略确认后再操作，否则历史对比证据会失效。
